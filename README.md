# Друк — лендинг

Готовый статический лендинг в светлом природном стиле. HTML + CSS + JavaScript, без npm, сборки, внешних шрифтов, аналитики и сторонних библиотек. Адаптирован для телефона и компьютера.

## 1. Подключите Google-форму

Откройте `config.js` и вставьте публичную ссылку для заполнения формы:

```js
window.DRUK_CONFIG = {
  betaFormUrl: "https://docs.google.com/forms/d/e/ВАШ_ID/viewform"
};
```

Можно использовать короткую ссылку `https://forms.gle/...`. Вставляйте ссылку для респондентов, не ссылку редактирования. Все три кнопки обновятся автоматически и откроют форму в той же вкладке.

Пока ссылка пустая, кнопки ведут к нижнему блоку и показывают «Запись в бету скоро откроется». Данные не собираются, успешная запись не имитируется. Для подключения и перехода к форме нужен JavaScript.

## 2. Загрузите на GitHub

1. Распакуйте архив.
2. Создайте пустой публичный репозиторий, например `druk-landing`.
3. Нажмите **uploading an existing file** (или **Add file → Upload files** в существующем репозитории).
4. Загрузите **содержимое** папки `druk-landing`, включая `assets`, и сохраните изменения в ветке `main`. Файл `index.html` должен лежать в корне репозитория, а не в дополнительной папке и не в ZIP.
5. Откройте **Settings → Pages**.
6. В **Build and deployment → Source** выберите **Deploy from a branch**.
7. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
8. После завершения публикации откройте адрес, который покажет GitHub Pages. Для репозитория `druk-landing` это обычно `https://ВАШ_ЛОГИН.github.io/druk-landing/`.

Все пути относительные: сайт работает и в подпапке репозитория. Специальный workflow не нужен. Пустой файл `.nojekyll` включён в архив; если интерфейс загрузки не показывает скрытые файлы, сайт с этими обычными HTML/CSS/JS-файлами работает и без него.

Альтернатива загрузке через браузер — из распакованной папки:

```bash
git init -b main
git add .
git commit -m "Add Druk landing page"
git remote add origin https://github.com/ВАШ_ЛОГИН/druk-landing.git
git push -u origin main
```

## Локальный просмотр

Просто откройте `index.html` в браузере. Сервер и установка зависимостей не требуются.

## Где что менять

| Файл | Назначение |
| --- | --- |
| `index.html` | Тексты и структура страницы |
| `styles.css` | Цвета, стеклянные поверхности и адаптивная вёрстка |
| `config.js` | Ссылка на форму |
| `script.js` | Подключение кнопок и состояние до открытия записи |
| `assets/druk.webp` | Оптимизированное изображение вашего персонажа |
| `assets/favicon.svg` | Иконка вкладки |

Исходное изображение содержит четыре ракурса. CSS показывает только верхний левый ракурс; сам файл сохранён без изменений. При замене на отдельное изображение персонажа уберите `width: 200%` у `.character img`, поставьте `width: 100%` и подберите `aspect-ratio` у `.character` под новое изображение.

Переписка на странице — иллюстрация возможностей, не работающий чат. Лендинг не содержит серверной части: после подключения формы заявки обрабатывает Google Forms. Голос, камера и подписки здесь не заявлены как доступные функции беты.

Файлы проекта подготовлены для загрузки; удалённый репозиторий и публикация ещё не созданы.

Инструкция по публикации сверена с [документацией GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
